# Fuente del catálogo AIS VesselType

La traducción de `VesselType` usa el documento de NOAA Marine Cadastre, [AIS Vessel Type and Group Codes used by the Marine Cadastre Project](https://coast.noaa.gov/data/marinecadastre/ais/VesselTypeCodes2018.pdf), que conserva la correspondencia entre código AIS y grupo/descripción de embarcación.

Como contraste normativo se consultó la [guía AIS de USCG Navigation Center](https://www.navcen.uscg.gov/sites/default/files/pdf/AIS/AISGuide.pdf), con los códigos de “Type of Ship” basados en ITU-R M.1371. El catálogo del notebook conserva la granularidad del código AIS observado: 31=Towing, 37=Pleasure craft, 60=Passenger, 70=Cargo y 80=Tanker.
